Fonts used by Quiz Night Slides
================================

Install these on any computer that will show the exported PowerPoint
(double-click each .ttf file and choose "Install"):

  Shrikhand-Regular.ttf            - headings, numbers, answers
  BricolageGrotesque-Regular.ttf   - body text
  BricolageGrotesque-Bold.ttf      - question text
  Salina (Bold)                    - slide titles; commercial font by Fontfabric,
                                     not included. Put a Salina .otf/.ttf in this
                                     folder and the app will use it.

Shrikhand and Bricolage Grotesque are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org) and come from the Google Fonts project.
The Bricolage Grotesque files are static instances of the variable font.
