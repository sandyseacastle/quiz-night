Import from CSV

One row per question. A new value in the category column starts a new round. To include pictures, audio or video, put the file name in the media column and select those files together with the CSV. Or choose a single .zip holding the CSV and folders of media, and write paths like round-1/images/flag.png in the media column. Download a template.

Column reference
ColumnWhat it does
categoryRound name. A change of value adds a category slide.
typetext, choice, image, audio or video. Optional: worked out from the media and options if blank.
questionThe question text.
answerThe answer. For multiple choice it can be the correct option's text or letter.
optionsChoices separated by |, or use columns option_a … option_f.
correctLetter of the correct option (optional if answer matches one).
mediaFile name of an image, audio or video file. With a .zip, a path relative to the CSV's folder (e.g. music/tune.mp3).
start, endClip start/end in seconds for audio and video.
factExtra info shown on the answer slide.
notesPrivate host notes.
category_subtitleSubtitle for the category slide.
